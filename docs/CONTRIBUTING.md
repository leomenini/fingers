# CONTRIBUTING.md

¡Gracias por querer colaborar!

Este proyecto busca construir una base de conocimiento académico abierta y verificable.

La prioridad siempre será la calidad del contenido.

---

# Antes de contribuir

Toda modificación debe respetar los siguientes principios:

* utilizar fuentes verificables;
* mantener un lenguaje claro;
* evitar interpretaciones personales;
* no copiar contenido protegido por derechos de autor.

---

Las contribuciones pueden ser de muchos tipos.

## Correcciones conceptuales

Corregir errores de contenido.

## Referencias

Agregar bibliografía o fuentes adicionales.

---

# Pull Requests

Toda modificación importante debe realizarse mediante Pull Request.

Los cambios serán revisados antes de integrarse al repositorio.

---

# Inteligencia Artificial

La IA puede utilizarse para generar borradores.

Sin embargo:

* todo contenido generado debe revisarse;
* la IA nunca constituye una fuente;
* la revisión humana sigue siendo obligatoria.

---

# Respeto por las fuentes

Este proyecto no distribuye libros protegidos por derechos de autor.

Las fuentes se citan y referencian.

El contenido del repositorio debe ser una elaboración propia de la comunidad.

---

# Código de conducta

Las discusiones deben mantenerse siempre en un marco de respeto académico.

El objetivo es mejorar el conocimiento, no ganar discusiones.
