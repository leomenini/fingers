    Crear un repositorio académico donde el conocimiento tenga el mismo ciclo de vida que el software libre: cada cambio es trazable, revisable, respaldado por fuentes y mantenido por una comunidad de responsables de cada área.
    "Queremos preservar y organizar el conocimiento generado en la facultad para facilitar el estudio, siempre respetando las fuentes y promoviendo la revisión humana." 
    "Preservar, organizar y mejorar el conocimiento académico generado por la universidad mediante un proceso abierto, trazable y revisado por la comunidad, donde la inteligencia artificial acelera el trabajo editorial pero nunca reemplaza la autoridad de las fuentes ni el criterio humano."
    "El contenido debe ser redactado por los colaboradores. Las fuentes sirven para verificar y respaldar afirmaciones, no para ser reproducidas."
    "La inteligencia artificial no forma parte del repositorio; forma parte del proceso editorial."
    Fase 0: Markdown, LaTeX y Git. 
    Fase 1: Una pequeña extensión de navegador para extraer transcripciones.
    Fase 2: Automatizar el flujo con Node.js.
    Fase 3: Un sitio estático que publique el contenido.
    Fase 4: Una base de datos cuando ya no alcance con archivos.
    Fase 5: Autenticación cuando aparezcan los primeros colaboradores.
    Fase 6: Sistema de revisión y Pull Requests propios si alguna vez GitHub deja de ser suficiente.
